## Data

- All demo documents in `data/demo/` are **synthetic**, generated by `tools/make_demo_docs.py`. Every company, person, address and ID number is fictitious. The ITC-HS codes (03061720 Vannamei shrimp, 03061740 black tiger shrimp) are real tariff codes from India's schedule.
- Background facts used in the presentation (ICC discrepancy rates, MPEDA FY 2025-26 export figures) are cited on the slides.

## AI-assisted development

This project was built during the hackathon with help from an AI coding assistant, which we used for research, code drafting and debugging. The team directed the design, reviewed the code, and tested and verified the results.
